# Notez — Web

Front-end do notez: editor de notas (Editor.js) com login via Google (Auth.js), rodando em SvelteKit.

## Comandos

```bash
# instalar dependências
bun install

# iniciar em modo de desenvolvimento
bun run dev
```

> Este app faz parte do monorepo `notez`. Veja o `README.md` na raiz para
> subir a stack completa (API + files + web) de uma só vez.
